No samples. Every note is a simulated string.

Main thread 01

Flutter Web canvas

Pointer events from up to ten fingers are hit-tested against string positions in StringCanvas. Each crossing becomes a pluck(string, velocity) message.

Audio thread 02

AudioWorkletProcessor

krar-processor fills 128 frames per process() call — 2.67 ms at 48 kHz — on a thread the UI can never block.

WebAssembly 03

Rust KrarEngine

Compiled with wasm-bindgen. Owns one string model per voice, the active qenet tuning, reverb and master gain.

Inside one string

Karplus–Strong

A burst of noise circulates through a delay line one period long. Each pass is averaged and damped, so high harmonics fade first — exactly how a gut string rings out.
